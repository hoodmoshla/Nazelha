# متطلبات Google Drive الرسمية التي جرى التحقق منها

## التنزيل من Drive API

واجهة `files.get` تقبل `alt=media` لإرجاع محتوى ملف Drive المخزّن. توثيق Google يذكر أن تنزيل المحتوى بهذه الطريقة يتطلب أحد نطاقات OAuth المدرجة، ومنها `drive.readonly`؛ وتصدير مستندات Google Workspace يتم عبر `files.export` بدلًا من ذلك. لذلك لا تكفي إعادة كتابة رابط المشاركة إلى رابط تنزيل عام لإثبات تكامل API رسمي أو تجاوز صلاحيات الملف.

المصدر: [Google Drive API — files.get](https://developers.google.com/workspace/drive/api/reference/rest/v3/files/get)

## تفويض تطبيق Android

توصي وثائق Android باستخدام `AuthorizationClient` لطلب صلاحيات بيانات Google عند تنفيذ الإجراء الذي يحتاج إليها. إعداد Android OAuth client يتطلب معرّف حزمة التطبيق وبصمة شهادة SHA‑1، مع تهيئة مشروع Google Cloud وشاشة الموافقة والمعلومات المطلوبة. لا يحتوي فرع Nazelha على إعداد OAuth/API أو حساب اختبار مرتبط بالحزمة التجريبية `com.snapnet.preview.debug`. يوجد معالج يطبّع بعض صيغ مشاركة ملفات Drive العامة إلى `uc?export=download&id=…`، لكنه ليس تكاملًا رسميًا مع Drive API ولا يطلب التفويض.

المصدر: [Android — Authorize access to user data](https://developer.android.com/identity/authorization)

## اختيار نطاق الوصول

النطاق `drive.readonly` يسمح بقراءة كل ملفات المستخدم لكنه نطاق مقيّد ويخضع لمراجعة Google المناسبة. أما `drive.file` فأضيق، ويقتصر على الملفات التي يختارها المستخدم أو يفتحها/يشاركها مع التطبيق عبر مسار اختيار متوافق؛ لا يخول التطبيق تنزيل أي رابط خاص يُلصق يدويًا. يجب اختيار نطاق التفويض وفق تجربة المستخدم المطلوبة، لا طلب النطاق الأوسع تلقائيًا.

## الحالة الحالية

لا يوجد في المستودع Client ID أو إعداد Google Cloud/OAuth أو حساب اختبار مرتبط بالحزمة التجريبية؛ لذلك لم يُنفذ تنزيل Drive الخاص عبر API. `GoogleDriveDownloadUrlHandler` يعالج روابط `/file/d/…` و`/open?id=…` و`/uc?id=…` فقط. بعد التطبيع، ينجح التنزيل فقط إذا سمح Google بالوصول العام وأعاد استجابة ملف مباشرة؛ لا يتجاوز صفحة تسجيل الدخول أو تحذير الفيروسات أو حدود الاستخدام، ولا يمرر Cookies أو رموز تفويض إلى مضيف آخر. اختبارات المعالج تحقق التطبيع، وليست إثباتًا لتنزيل حي من كل ملفات Drive.

## حدود التنفيذ

يجب ألا تُرسل Cookies أو رموز OAuth عبر تحويل إلى نطاق آخر، وألا تُسجَّل الرموز في السجلات أو تحفظ داخل ملفات المصدر. روابط Drive الخاصة أو المقيدة تحتاج تفويضًا سليمًا؛ إذا لم يكن التفويض مهيّأ، فالنتيجة الصادقة هي إظهار أن المصدر يتطلب صلاحيات أو أن الرابط لا يمكن تنزيله، لا الادعاء بأن الرابط الخاص مدعوم. لا يوجد دعم لتصدير مستندات Google Workspace عبر `files.export` في هذا الإصدار.
