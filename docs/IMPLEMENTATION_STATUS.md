## الحدود والقيود

Google Drive غير مدمج رسميًا، لأن الملفات الخاصة تتطلب OAuth/API بإعداد واختبار لم يتوفرا؛ لم نتجاوز صلاحيات المصدر. Dropbox يخضع لتطبيع الرابط فقط دون تنزيل حي. لا اختبار على هاتف أو محاكي، ولا ضمان لتجديد الروابط المنتهية أو تجاوز DRM/CAPTCHA. استعادة الطابور عند فتح التطبيق موجودة، لكن بدء العمل بعد إقلاع Android غير مدمج.
