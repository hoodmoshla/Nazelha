# نزّلها — حالة التنفيذ والتسليم

## النتيجة

اكتمل مرشح **Nazelha 1.0.7** ونُشر كإصدار تجريبي مسبق على GitHub. الوسم `nazelha-preview-v1.0.7-2026-10-27` يشير إلى commit `ad9767e434773adb46bb077a2c114ef88ccc7cda`، واجتاز تشغيل GitHub Actions رقم [40580027983](https://github.com/hoodmoshla/Nazelha/actions/runs/40580027983). الملف المنشور APK واحد لمعمارية ARM64، والحزمة `com.snapnet.preview.debug` واسم التطبيق «نزّلها — فيديو وملفات».

## ما اكتمل

- واجهة عربية حديثة باتجاه RTL وشريط تنقل سفلي: الرئيسية، التنزيلات، الملفات، المتصفح، المزيد.
- لوحة رئيسية لإدخال رابط التنزيل، ملخص الحالات، وآخر الملفات، مع حالات فارغة وإجراءات واضحة.
- إدارة تنزيلات فعلية للفيديو والصوت والملفات، تشمل حالات الجاري والمكتمل والمتوقف، التقدم، الإيقاف والاستئناف والإلغاء وإعادة المحاولة.
- مدير ملفات يدعم البحث والتصنيف والفرز والعرض شبكة/قائمة والتحديد المتعدد، والفتح والمشاركة وإعادة التسمية والحذف المؤكد.
- متصفح WebView مدمج مع تقييد البروتوكولات الخارجية وسياسات أمان للروابط.
- مسارات تنزيل عبر HTTP/HTTPS وyt-dlp؛ بقيت محركات FFmpeg وPython/yt-dlp وaria2 وQuickJS المطلوبة لوظائف الوسائط والتنزيل.
- دعم الوضعين الفاتح والداكن، مع تهيئة الألوان والأزرار لتجربة هاتف ويد واحدة.
- فُعّل R8 وتقليص الموارد. اجتازت النسخة المصغّرة التحقق الآلي، ولم يظهر خلل وظيفي منسوب إلى التصغير؛ لذلك لم يُستبدل APK ببناء كامل غير مصغّر.

## التثبيت والتوافق

يستخدم 1.0.7 شهادة Debug مختلفة، لذلك لا يقبله Android كتحديث فوق 1.0.6. احفظ أو صدّر ما تحتاجه من بيانات التطبيق قبل إزالة النسخة السابقة والتثبيت. بقي إصدار 1.0.6 وملفاته دون حذف أو استبدال. لم يُختبر التثبيت على هاتف فعلي؛ اختبارات الواجهة الآلية كانت على محاكي Android 15.

## الحدود المعروفة

- لا يتوفر تكامل OAuth أو Drive API؛ لا يستطيع التطبيق الوصول إلى ملفات Google Drive الخاصة، وبعض روابط Drive العامة فقط يمكن تطبيعها.
- دعم Dropbox والروابط العامة لا يعني تحققًا حيًا شاملًا لكل رابط أو مرفق.
- اكتشاف روابط HTML محدود الحجم والعدد؛ لا ينفذ JavaScript أو نماذج تسجيل الدخول ولا يتجاوز CAPTCHA أو DRM أو صلاحيات المصدر.
- لا يبدأ التطبيق المهام عند إقلاع Android؛ تُستعاد المهام غير المكتملة عند فتحه. ولا يعاد تشغيل custom command المقطوع تلقائيًا لتجنب تكرار آثاره.
- هذا APK إصدار Debug تجريبي، وليس إصدارًا موقعًا بمفتاح إنتاج.
