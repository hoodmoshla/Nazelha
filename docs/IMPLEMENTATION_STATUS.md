## الخلاصة

اكتمل مرشح Nazelha v1.0.6 ونُشر كإصدار تجريبي عام (prerelease). Tag الإصدار `nazelha-preview-v1.0.6-2026-10-27` يشير إلى commit `15a41aad5ef25404c57a317ae689ee0829f65b90`، وهو commit الذي اجتاز GitHub Actions. التطبيق باسم «نزّلها — فيديو وملفات»، معرّف الحزمة `com.snapnet.preview.debug`، وبناء ARM64. كل العمل في مستودع Nazelha؛ لم يُعدّل مستودع `hoodmoshla/SnapNet` أو فروعه أو إصداراته.

## التوقيع والتوافق

استُخدم توقيع Debug مستقل كما اختار كِنان. **لن يقبل Android هذا APK كتحديث فوق APK المرحلة الأولى رغم تطابق application ID**؛ لا تُزل النسخة القديمة أو بياناتها قبل حفظ ما تحتاجه. هذا ليس مفتاح توقيع إنتاجيًا. لا توجد مفاتيح خاصة أو رموز وصول ضمن الفرع أو الأصول المنشورة.

## الحدود التي يجب الإبقاء عليها في وصف التطبيق

- لا يوجد OAuth أو Drive API؛ لا يمكن الوصول إلى Google Drive الخاص أو مستندات Google Workspace. تحويل بعض روابط Drive العامة لا يضمن التنزيل من كل رابط.
- Dropbox خضع لتطبيع الرابط واختبارات وحدات، لا لإثبات تنزيل حي شامل. اختبار README العام من GitHub لا يثبت دعم كل مرفق.
- اكتشاف HTML لا ينفذ JavaScript أو نماذج تسجيل الدخول، ولا يتعامل مع CAPTCHA؛ لا تُمرر Cookies لمضيف مختلف ولا يُتجاوز DRM أو صلاحيات المصدر أو انتهاء الرابط.
- لا يتوفر هاتف أو محاكي متصل، لذلك لم يُختبر عمليًا تنزيل الفيديو/الصوت الطويل أو الأداء والبطارية والإشعارات والخلفية على جهاز.
- تُستعاد المهام غير المكتملة عند فتح التطبيق؛ لا يوجد بدء عند إقلاع Android. لا يعاد تشغيل custom command المقطوع تلقائيًا، لتجنب تكرار الآثار الجانبية.
