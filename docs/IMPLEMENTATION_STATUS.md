# نزّلها — حالة التنفيذ والتحقق

## الخلاصة

اكتمل تنفيذ المرشح التجريبي v1.0.6 على فرع `feature/direct-http-downloads-stage1-2026-10-27`، اعتمادًا على عمل المرحلة الأولى دون إعادة بنائه أو فقدان اختباراته. الاسم «نزّلها — فيديو وملفات»، والحزمة `com.snapnet.preview.debug`، والبناء المستهدف `arm64-v8a`. جميع تغييرات التطبيق تخص مستودع Nazelha فقط؛ لم يُعدّل `hoodmoshla/SnapNet` أو أي فرع أو إصدار فيه.

نجحت الجولة المحلية الكاملة: **147 اختبار وحدة** بلا فشل أو أخطاء أو تجاوز، ونجح Lint والبناء ARM64. لم يُنشر v1.0.6 بعد؛ يجب أن ينجح GitHub Actions على commit الإصدار وأن يُفحص ملف APK الناتج قبل إنشاء prerelease العام. حمولة v1.0.5 القديمة محفوظة، لكنها ليست الإصدار النهائي ولن تُنشر بهذا الوصف.

## المراحل

| المرحلة | الحالة والنتيجة |
|---|---|
| 1 — الأساس والهوية | اسم عربي، واجهة عربية وRTL قدر الإمكان، أيقونات Launcher وAdaptive، الحزمة التجريبية المحفوظة. الإصدار البرمجي المرشح `1.0.6-debug` وversion code `100060402`. |
| 2 — مصادر الملفات | HTTP/HTTPS مباشر مع فحص العناوين الخاصة والمحجوزة والتحويلات والاسم/النوع/الحجم. معالجات لروابط GitHub العامة والمرفقات، وDropbox العام، وصيغ مشاركة ملفات Drive العامة. معالج Drive يطبع الرابط فقط ولا يدمج OAuth/API. |
| 3 — مدير التنزيلات | طابور الفيديو والصوت والملفات، تزامن 1–5، إيقاف واستئناف وإلغاء وإعادة تشغيل صريحة، وفحص مساحة التخزين. تُعاد المحاولة تلقائيًا لأخطاء الشبكة ومعدل الطلبات المؤقتة فقط، بحد ثلاث محاولات وإرجاء أسي. الاستئناف يحترم Range/ETag/Last-Modified عندما تتوفر، ويُتخلّص من ملفات Direct HTTP المؤقتة بعد الإلغاء دون حذف الوجهة المكتملة. |
| 4 — إدارة الملفات | بحث وتصنيف وفرز وعرض وفتح ومشاركة وإعادة تسمية وحذف مؤكد، باستخدام صلاحيات Android وSAF ضمن مجلد الوجهة. |
| 5 — الروابط المعقدة | اكتشاف محدود لروابط تنزيل صريحة في HTML عام، بحد 1 MiB و30 رابطًا مرشحًا، يعرضها للاختيار قبل التنزيل. لا ينفذ JavaScript أو النماذج ولا يزحف المواقع؛ يستمر استخدام yt-dlp فقط للمواقع التي يدعمها فعلًا. |
| 6 — الاختبارات والمراجعة | نجحت 147 حالة JVM/HTTP. شملت المراجعة الاستعادة والإلغاء والتنظيف والاستئناف، SSRF، حجب الروابط في السجلات والنسخ الاحتياطية، وروابط Google Drive. لم يُختبر التطبيق على هاتف فعلي أو محاكي متصل. |
| 7 — التسليم التجريبي | APK محلي v1.0.6 مبني للحزمة والاسم وABI المطلوبة. ملف التوزيع النهائي سيُؤخذ من GitHub Actions بعد نجاح التشغيل والتحقق من التوقيع والبصمة، ثم يُنشر كـprerelease مع sidecar SHA-256. |

## نتائج التحقق المحلي

- **Unit tests:** 147 اختبارًا؛ 0 فشل، 0 أخطاء، 0 تجاوز. فُعّلت اختبارات HTTP الحية المحدودة بـ`NAZELHA_LIVE_HTTP_TESTS=1`.
- **Android Lint:** 0 أخطاء، 200 تحذير، ومعلومة واحدة. لا توجد ملاحظة `UsableSpace` بعد إضافة rationale موضعي، وأُصلح تحذير صيغة الجمع الخاص بعدد ملفات مدير الملفات. بقيت 12 ملاحظة `PluralsCandidate` في موارد نصية أخرى، وتحذير واحد لشكل أيقونة round موجودة، وتحذير تكرار أيقونات، إلى جانب تحذيرات تحديث الاعتماديات والواجهات المهجورة والموارد. هذه ملاحظات غير مانعة وليست ميزات مختبرة.
- **Build:** نجح `:app:assembleGithubPreviewDebug` مع فلتر `arm64-v8a`. تحقق محليًا من الحزمة `com.snapnet.preview.debug` والاسم العربي ووجود المكتبة الأصلية `arm64-v8a`؛ لا يُستخدم APK المحلي بدل ملف CI النهائي.
- **لا يوجد اختبار جهاز:** لا تتوفر بيئة هاتف أو محاكي متصل؛ لم تُقَس استهلاكات البطارية والذاكرة أو أداء التنزيل الطويل والإشعارات والخلفية على جهاز Android فعلي.

## الخصوصية والاستعادة

تُستخدم معرّفات مهام SHA-256 opaque بدل إدراج URL في المعرّف. تُنقح الروابط والرموز في سجلات yt-dlp وتقارير الأخطاء والنسخ الاحتياطية اليدوية، كما تستبعد قواعد Android قاعدة البيانات التي تحتوي CookieProfile وطابور المهام الذي قد يحمل روابط موقعة من النسخ السحابي ونقل الجهاز.

تُستعاد المهام غير المكتملة عند فتح التطبيق؛ لا يوجد WorkManager أو بدء تلقائي للتنزيل عند إقلاع الهاتف. لا يُعاد تشغيل custom command تلقائيًا بعد انقطاع العملية، تفاديًا لتكرار الأوامر ذات الآثار الجانبية؛ يمكن للمستخدم اختيار إعادة تشغيله صراحةً.

## المصادر والقيود

- جرى اختبار تنزيل ملف README عام من GitHub؛ لا يثبت ذلك دعم جميع مرفقات وإصدارات GitHub.
- اختبارات Dropbox وDrive تتحقق من تطبيع الروابط فقط، ولا تثبت تنزيلًا حيًا شاملًا من كل رابط.
- Google Drive الخاص أو المقيد غير مدعوم دون OAuth/API وإعداد Google Cloud وموافقة المستخدم. لا يتجاوز التطبيق تسجيل الدخول أو صفحات تحذير الفيروسات، ولا يصدّر مستندات Google Workspace.
- اكتشاف HTML محدود للروابط الصريحة؛ لا يتعامل مع تسجيل الدخول أو CAPTCHA أو صفحات JavaScript، ولا يمرر Cookies إلى مضيف خارجي. لا يتجاوز DRM أو صلاحيات المصدر أو انتهاء الروابط.
- لم يُختبر تنزيل فيديو/صوت طويل أو قائمة تشغيل على جهاز فعلي؛ لا تدّعِ هذه النتيجة بناءً على اختبارات الوحدات وحدها.

## التوقيع والنشر

سيستخدم إصدار v1.0.6 توقيع Debug مستقلًا عن APK المرحلة الأولى، وفق اختيار كِنان. ينبغي التحقق من شهادة ملف CI النهائي ومقارنتها بمرجع المرحلة الأولى قبل النشر. **لن يقبل Android ملفًا بتوقيع مختلف كتحديث فوق APK المرحلة الأولى حتى مع تطابق الحزمة**؛ لا تزل النسخة القديمة أو بياناتها. هذا ليس مفتاح توقيع إنتاجيًا.

لم يُنشأ Tag أو Release لـv1.0.6 بعد. بعد نجاح CI والتحقق من الحزمة والاسم وABI والتوقيع وحجم APK وSHA-256، ستُنشر معاينة prerelease في `hoodmoshla/Nazelha` مع APK وملف checksum وملاحظات صريحة عن القيود. لا تستخدم حمولة `nazelha-preview-v1.0.5-2026-10-27` لهذا الإصدار.

## إعادة البناء والاختبار

المتطلبات: JDK 21 وAndroid SDK 35. الأوامر المستخدمة محليًا وسير التحقق:

```bash
ANDROID_HOME="$HOME/Android/Sdk" \
ANDROID_SDK_ROOT="$HOME/Android/Sdk" \
NAZELHA_LIVE_HTTP_TESTS=1 \
./gradlew :app:testGithubPreviewDebugUnitTest \
  :app:lintGithubPreviewDebug :app:assembleGithubPreviewDebug \
  -PnoSplits -PABI_FILTERS=arm64-v8a \
  --no-daemon --no-configuration-cache
```

المصدر مرخص تحت GPL v3؛ يجب إتاحة المصدر الموافق عند التوزيع حسب شروط الرخصة. لم يُستخدم Force Push ولم يُعدل `main`.
