# Nazelha — نزّلها | فيديو وملفات

مشروع Android مستقل مشتق من [SnapNet](https://github.com/hoodmoshla/SnapNet)، لتنزيل الفيديو والصوت والملفات والروابط وإدارة التنزيلات. الاسم المعتمد للتطبيق هو **«نزّلها — فيديو وملفات»**؛ لم تُطبَّق الهوية الجديدة على ملف APK المرجعي للمرحلة الأولى.

## الحالة الحالية

هذا التسليم يقتصر على نقل المرحلة الأولى الموجودة مسبقًا: تحليل روابط HTTP/HTTPS المباشرة، معاينة معلومات الملف، وتنزيله عبر نظام المهام الحالي، مع اختبارات المحلّل والنقل. لا يعني نجاح اختبارات JVM أن جميع مسارات الواجهة أو الإلغاء والاستئناف على الهاتف قد ثبتت سلامتها.

- نقطة الأساس: SnapNet `v1.0.5`، بالـCommit `07929caf3cba21ebf7efefd244d939d4887cf4db`.
- فرع المرحلة الأولى: `feature/direct-http-downloads-stage1-2026-10-27`.
- حزمة APK التجريبي الحالي: `com.snapnet.preview.debug`.
- الاسم الفعلي داخل APK الحالي: `SnapNet Debug`، مع أيقونة SnapNet السابقة.
- ABI: `arm64-v8a` فقط. التوقيع: Android Debug مستقل عن شهادة إصدار SnapNet الرسمية.
- لم يُنشأ Release رسمي، ولم تُنفَّذ المراحل التالية أو يُختبر التطبيق على هاتف فعلي ضمن هذا التسليم.

تفاصيل أصل المشروع في [سجل المصدر والنقل](docs/UPSTREAM.md). نتائج التسليم والتحذيرات تُسجَّل في [توثيق المرحلة الأولى](docs/phase1/verification.md).

## استقلال المشروع

تاريخ Git والترخيص وإشعارات الحقوق الأصلية محفوظة. جرى نسخ التغييرات المحلية غير المحفوظة في Commit من مساحة SnapNet إلى Nazelha دون تعديل مساحة المصدر. لم تُنقل مفاتيح أو كلمات مرور أو رموز وصول.

أُرشفت workflows الأصلية تحت `docs/upstream-workflows/` بامتداد `.disabled` حتى لا يؤدي استيراد المشروع إلى نشر إصدار أو تشغيل مهام إدارية موروثة. لا توجد workflow نشر فعّالة في هذا التسليم، ولم يُنسخ توقيع SnapNet الرسمي أو إعداد أسراره.

## التحقق محليًا

يتطلب المشروع JDK 21 وAndroid SDK 35 وأدوات البناء المناسبة لـGradle Wrapper المضمّن.

```bash
SNAPNET_LIVE_HTTP_TESTS=1 ./gradlew :app:testGithubPreviewDebugUnitTest \
  -PnoSplits -PABI_FILTERS=arm64-v8a \
  --no-daemon --no-configuration-cache
```

`SNAPNET_LIVE_HTTP_TESTS=1` يفعّل اختبار ملف GitHub العام؛ بدونه يُتخطّى ذلك الاختبار. الاختبارات الأخرى تستخدم خادم HTTP محليًا. لا تُعَد هذه الاختبارات بديلًا لاختبار الهاتف أو مسار نشر الملفات وSD card.

لإنشاء بناء تجريبي لاحقًا، عند الحاجة والموافقة على تغييره:

```bash
./gradlew :app:assembleGithubPreviewDebug -PnoSplits -PABI_FILTERS=arm64-v8a
```

إعداد البناء الموروث يغيّر التوقيع إذا وُجد `keystore.properties`؛ لا تُنشئه من مفاتيح SnapNet ولا تستخدمه لهذا البناء التجريبي. ملفات التوقيع ومخرجات البناء والتحقق المحلي غير مرفوعة إلى Git.
