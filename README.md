# نزّلها — فيديو وملفات

تطبيق Android تجريبي عربي لتنزيل الفيديو والصوت والملفات وإدارة مهام التنزيل والملفات المحفوظة. الأعمال والإصدارات هنا في مستودع Nazelha المستقل؛ لم يُعدّل هذا المشروع مستودع SnapNet أو فروعه أو إصداراته.

## ما يقدمه التطبيق

- الاسم الظاهر **«نزّلها — فيديو وملفات»**، العربية افتراضية ودعم RTL، مع أيقونات Android التكيفية والقياسية. معرّف الحزمة `com.snapnet.preview.debug`.
- تنزيل HTTP/HTTPS مباشر مع حظر عناوين الشبكات الخاصة والمحجوزة، ومعالجة التحويلات الآمنة، واستخراج الاسم والنوع والحجم، وفحص مساحة التخزين، والاستئناف عند تحقق شروط الخادم وبيانات التحقق.
- معالجات لروابط GitHub العامة وملفات `blob` والإصدارات، وروابط مشاركة Dropbox العامة، وبعض صيغ مشاركة ملفات Google Drive العامة. دعم Dropbox وDrive هنا لا يضمن أن الملف متاح أو أن التنزيل الحي نجح لكل رابط.
- اكتشاف محدود لروابط ملفات صريحة من صفحة HTML عامة باستخدام Jsoup: حتى 1 MiB و30 رابطًا مرشحًا، ثم يختار المستخدم الرابط قبل تنزيله. لا ينفذ JavaScript أو النماذج أو الزحف، ولا يمرر Cookies إلى مضيف آخر.
- طابور موحد للفيديو والصوت والملفات، حد تزامن قابل للضبط من 1 إلى 5، وإيقاف واستئناف وإلغاء وإعادة تشغيل صريحة. تُعاد المحاولة تلقائيًا لأخطاء الشبكة المؤقتة ومعدل الطلبات فقط، بحد أقصى 3 محاولات وإرجاء أسي.
- حفظ حالة الطابور واستعادة المهام غير المكتملة عند فتح التطبيق. لا تُشغّل أوامر المستخدم المخصصة تلقائيًا بعد إغلاق العملية؛ يمكن للمستخدم إعادة تشغيلها صراحةً. لا يوجد بدء تلقائي عند إقلاع الهاتف.
- مدير ملفات للبحث والتصنيف والفرز والفتح والمشاركة وإعادة التسمية والحذف المؤكد، ضمن أذونات Android وSAF.
- تُحجب عناوين URL والرموز الحساسة في سجلات التنزيل وتقارير الأخطاء والنسخ الاحتياطية اليدوية. تستبعد قواعد Android قاعدة البيانات التي تحتوي ملفات تعريف الارتباط وطابور المهام الذي قد يحمل روابط مؤقتة من النسخ السحابي ونقل الجهاز.

## التحقق والقيود المعروفة

نجحت محليًا **147 حالة اختبار وحدة**: 0 فشل، 0 أخطاء، 0 تجاوز. نجح Android Lint والبناء ARM64؛ بقي 0 خطأ و200 تحذير ومعلومة واحدة. لا توجد ملاحظة `UsableSpace` بعد المعالجة، وأُصلح تنبيه صيغة الجمع في رسالة عدد ملفات مدير الملفات. ما زالت 12 ملاحظة `PluralsCandidate` في موارد نصية أخرى، وتحذير واحد لشكل أيقونة round قديمة وتحذير تكرار أيقونات، إضافة إلى تحذيرات الاعتماديات والواجهات المهجورة والموارد.

Google Drive لا يستخدم OAuth أو Drive API في هذا الإصدار. معالج Drive يطبع بعض روابط الملفات العامة فقط؛ لا يفتح الملفات الخاصة ولا يتجاوز تسجيل الدخول أو صفحة تحذير الفيروسات أو حدود الاستخدام، ولا يدعم تصدير مستندات Google Workspace. اختبارات Dropbox وDrive تتحقق من تطبيع الرابط ولا تثبت تنزيلًا حيًا شاملًا. لا يتجاوز التطبيق DRM أو CAPTCHA أو صلاحيات المصدر أو انتهاء الروابط.

لم يتوفر هاتف أو محاكي Android متصل؛ لذلك لم تُختبر على جهاز فعلي الخلفية والبطارية والإشعارات وإعادة التشغيل أو تنزيلات الفيديو/الصوت الطويلة. استعادة الطابور تحصل عند فتح التطبيق، ولا يوجد تشغيل عند إقلاع الهاتف.

## البناء وإعادة الاختبار

المتطلبات: JDK 21 وAndroid SDK 35. لبناء معاينة ARM64:

```bash
ANDROID_HOME="$HOME/Android/Sdk" \
ANDROID_SDK_ROOT="$HOME/Android/Sdk" \
./gradlew :app:assembleGithubPreviewDebug \
  -PnoSplits -PABI_FILTERS=arm64-v8a --no-daemon
```

لتشغيل الاختبارات وLint والبناء كما في سير التحقق:

```bash
ANDROID_HOME="$HOME/Android/Sdk" \
ANDROID_SDK_ROOT="$HOME/Android/Sdk" \
NAZELHA_LIVE_HTTP_TESTS=1 \
./gradlew :app:testGithubPreviewDebugUnitTest \
  :app:lintGithubPreviewDebug :app:assembleGithubPreviewDebug \
  -PnoSplits -PABI_FILTERS=arm64-v8a \
  --no-daemon --no-configuration-cache
```
