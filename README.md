# نزّلها — فيديو وملفات

تطبيق Android تجريبي عربي لتنزيل الفيديو والصوت والملفات وإدارة المهام والملفات المحفوظة. انطلق العمل من الفرع `feature/direct-http-downloads-stage1-2026-10-27` عند `c08ce91a99df03e6703de41a80a312d7698886ab`. التغييرات والبناء والنشر المقترح تخص مستودع Nazelha فقط؛ لم يُعدّل مستودع SnapNet أو فروعه أو إصداراته.

## ما نُفّذ

- اسم التطبيق **«نزّلها — فيديو وملفات»** وأيقونات Android قياسية ودائرية وتكيفية وأحادية اللون، والعربية افتراضية مع دعم RTL. معرّف الحزمة التجريبي `com.snapnet.preview.debug`.
- تنزيل HTTP/HTTPS المباشر، والتحويلات الآمنة، واستخراج الاسم والنوع والحجم، وحجب عناوين الشبكة الخاصة والمحجوزة. لا يضيف هذا المسار Cookies أو ترويسات مصادقة ولا يقبل بيانات اعتماد داخل URL.
- تطبيع روابط GitHub العامة وملفات `blob` والإصدارات والمرفقات، ومعالج مستقل لروابط مشاركة Dropbox العامة باستخدام `dl=1`. تطبيع Dropbox مختبر بوحدات؛ لم يُثبت تنزيل حي من كل خدمة.
- طابور موحد للفيديو والصوت والملفات، وحد تزامن 1–5، وإيقاف واستئناف وإلغاء وإعادة محاولة يدوية. الاستئناف مشروط بمدقق الخادم والنطاق الصحيح، مع نشر آمن للملف النهائي.
- شاشة ملفات للبحث والتصنيف والفرز والفتح والمشاركة وإعادة التسمية والحذف المؤكد، ورسائل عربية للأخطاء الحساسة مع تنقيح المعلومات السرية عند نسخ التقرير.

## تنبيه التثبيت والتوقيع

شهادة APK المرحلة الأولى مختلفة عن شهادة هذا المرشح، رغم تطابق معرّف الحزمة. **لن يقبل Android هذا الملف كتحديث فوق APK المرحلة الأولى.** لا تزل النسخة القديمة أو بياناتها قبل حفظ ما تحتاجه؛ لم تُحذف نسخة أو بيانات. ولا تُعامل شهادة Debug على أنها توقيع إصدار إنتاجي.

## الحدود الصريحة

**Google Drive غير مدمج رسميًا** في هذا البناء؛ لا يوجد إعداد OAuth/API أو حساب اختبار للحزمة التجريبية، والملفات الخاصة تتطلب تفويضًا صحيحًا. صفحات HTML تواصل إلى المواقع واستخراج `yt-dlp` المدعوم فعليًا؛ لا يوجد زاحف عام لكل روابط الويب. لا يضمن التطبيق تجاوز DRM أو CAPTCHA أو صلاحيات المصدر أو تجديد الروابط المنتهية.

لا يتوفر هاتف أو محاكي متصل في بيئة التحقق؛ لذلك لم تُختبر عمليًا استعادة العملية بعد إعادة تشغيل Android، أو الخلفية والبطارية والإشعارات، أو تنزيلات الفيديو والصوت داخل APK. كما أن تطبيع روابط Dropbox لا يثبت تنزيلًا حيًا منها. المهام غير المكتملة المحفوظة في MMKV تُستعاد عند فتح التطبيق، ولا يوجد بدء تلقائي عند إقلاع الهاتف.

## البناء وإعادة الاختبار

المتطلبات: JDK 21 وAndroid SDK 35. لبناء معاينة ARM64:

```bash
ANDROID_HOME="$HOME/Android/Sdk" \
ANDROID_SDK_ROOT="$HOME/Android/Sdk" \
./gradlew :app:assembleGithubPreviewDebug \
  -PnoSplits -PABI_FILTERS=arm64-v8a --no-daemon
```

لتشغيل اختبارات الوحدات وLint والبناء:

```bash
ANDROID_HOME="$HOME/Android/Sdk" \
ANDROID_SDK_ROOT="$HOME/Android/Sdk" \
NAZELHA_LIVE_HTTP_TESTS=1 \
./gradlew :app:testGithubPreviewDebugUnitTest \
  :app:lintGithubPreviewDebug :app:assembleGithubPreviewDebug \
  -PnoSplits -PABI_FILTERS=arm64-v8a \
  --no-daemon --no-configuration-cache
```
