# نزّلها — فيديو وملفات

تطبيق Android تجريبي عربي لتنزيل الفيديو والصوت والملفات وإدارة مهام التنزيل والملفات المحفوظة. يعمل المشروع في مستودع Nazelha المستقل وعلى فرع المعاينة `feature/direct-http-downloads-stage1-2026-10-27`؛ لا يغيّر هذا العمل مستودع SnapNet أو فروعه أو إصداراته.

## ما يقدمه التطبيق

- الاسم الظاهر **«نزّلها — فيديو وملفات»**، العربية افتراضية ودعم RTL، مع أيقونات Android التكيفية والقياسية. معرّف الحزمة التجريبي `com.snapnet.preview.debug`.
- تنزيل HTTP/HTTPS مباشر مع فحص الوجهة لحظر عناوين الشبكات الخاصة والمحجوزة، ومعالجة التحويلات الآمنة، واستخراج الاسم والنوع والحجم، وفحص المساحة، ودعم الاستئناف عند تحقق شروط الخادم وبيانات التحقق.
- معالجات قابلة للاختبار لروابط GitHub العامة وملفات `blob` والإصدارات، وروابط مشاركة Dropbox العامة، وبعض صيغ مشاركة ملفات Google Drive العامة. لم يثبت اختبار حي التنزيل من كل خدمة؛ تطبيع روابط Dropbox وDrive وحده لا يعني أن الملف سيُتاح من الخادم.
- اكتشاف محدود لروابط الملفات من صفحة HTML عامة باستخدام Jsoup: حتى 1 MiB و30 رابطًا مرشحًا، ثم يختار المستخدم الرابط قبل تنزيله. لا ينفّذ JavaScript أو النماذج، ولا يزحف الروابط أو يمرر ملفات تعريف الارتباط إلى مضيف آخر.
- طابور موحد للفيديو والصوت والملفات، حد تزامن قابل للضبط من 1 إلى 5، إيقاف واستئناف وإلغاء وإعادة تشغيل صريحة. تُعاد المحاولة تلقائيًا لأخطاء الشبكة المؤقتة ومعدل الطلبات فقط، بحد أقصى 3 محاولات وإرجاء أسي؛ الأخطاء الدائمة والمصادقة والمساحة لا يعاد طلبها تلقائيًا.
- حفظ حالة الطابور واستعادة المهام غير المكتملة عند فتح التطبيق. لا تُشغّل أوامر المستخدم المخصصة تلقائيًا بعد إغلاق العملية؛ يمكن للمستخدم بدءها من جديد صراحةً. لا يوجد تشغيل تلقائي عند إقلاع الهاتف.
- مدير ملفات يدعم البحث والتصنيف والفرز والفتح والمشاركة وإعادة التسمية والحذف المؤكد، ضمن أذونات Android وSAF.
- حماية الخصوصية: تُحجب عناوين URL والرموز الحساسة في سجلات التنزيل وتقارير الأخطاء والنسخ الاحتياطية اليدوية. تستبعد قواعد Android نسخ قاعدة البيانات التي تحتوي ملفات تعريف الارتباط وطابور المهام الذي قد يحمل روابط مؤقتة.

## التحقق المحلي

شغّلت الجولة الكاملة محليًا: **147 اختبار وحدة**، 0 فشل، 0 أخطاء، 0 تجاوز؛ ونجح Android Lint والبناء ARM64 دون أخطاء مانعة. بقي في Lint **200 تحذير ومعلومة واحدة**، منها تحذيرات إصدارات اعتماديات وواجهات مهجورة وموارد قديمة؛ أُزيل تحذير `UsableSpace` من مواضع فحص التخزين، وأُصلح مورد عدد الملفات المستخدم في مدير الملفات. ما زالت 12 ملاحظة `PluralsCandidate` أخرى في موارد نصية مختلفة، وتحذير واحد لشكل أيقونة round قديمة وتحذير تكرار أيقونات؛ لا تُعامل هذه التحذيرات على أنها اختبارات ناجحة أو أخطاء مانعة.

نجح بناء محلي للمرشح `1.0.6-debug` بالحزمة `com.snapnet.preview.debug` والاسم «نزّلها — فيديو وملفات» وABI `arm64-v8a`. **هذا البناء المحلي ليس ملف التوزيع النهائي**؛ سيُستخدم ملف APK الناتج عن GitHub Actions بعد نجاح التحقق على commit الإصدار، وستُطابق بصمته مع ملف SHA-256 المرفق.

## التوقيع والتثبيت

يستخدم المرشح توقيع Debug مستقلًا عن توقيع APK المرحلة الأولى، كما طلب كِنان. لذلك **لن يقبل Android APK النهائي كتحديث فوق APK المرحلة الأولى** حتى مع تطابق معرّف الحزمة. لا تزل التطبيق القديم أو بياناته قبل حفظ ما تحتاجه. هذا ليس توقيعًا إنتاجيًا.

## الحدود المعروفة

Google Drive لا يستخدم OAuth أو Drive API في هذا الإصدار. المعالج يطبع بعض روابط الملفات العامة إلى صيغة تنزيل عادية فقط؛ لا يفتح الملفات الخاصة، ولا يتجاوز تسجيل الدخول أو صفحة تحذير الفيروسات أو حدود الاستخدام. لا يدعم تصدير مستندات Google Workspace.

Dropbox مغطى باختبارات تطبيع الرابط، لا بإثبات تنزيل حي شامل. اكتشاف HTML لا يتعامل مع الصفحات المعتمدة على JavaScript أو تسجيل الدخول أو CAPTCHA. لا يتجاوز التطبيق DRM أو صلاحيات المصدر أو الروابط المنتهية. لم يتوفر هاتف أو محاكي Android متصل؛ لذلك لم تُختبر على جهاز فعلي الخلفية والبطارية والإشعارات وإعادة التشغيل أو تنزيل الفيديو/الصوت الطويل عمليًا. استعادة الطابور تحصل عند فتح التطبيق، ولا يوجد بدء بعد إقلاع الهاتف.

## البناء وإعادة الاختبار

المتطلبات: JDK 21 وAndroid SDK 35. لبناء معاينة ARM64:

```bash
ANDROID_HOME="$HOME/Android/Sdk" \
ANDROID_SDK_ROOT="$HOME/Android/Sdk" \
./gradlew :app:assembleGithubPreviewDebug \
  -PnoSplits -PABI_FILTERS=arm64-v8a --no-daemon
```

لتشغيل الاختبارات وLint والبناء كما في سير التحقق:

```bash
ANDROID_HOME="$HOME/Android/Sdk" \
ANDROID_SDK_ROOT="$HOME/Android/Sdk" \
NAZELHA_LIVE_HTTP_TESTS=1 \
./gradlew :app:testGithubPreviewDebugUnitTest \
  :app:lintGithubPreviewDebug :app:assembleGithubPreviewDebug \
  -PnoSplits -PABI_FILTERS=arm64-v8a \
  --no-daemon --no-configuration-cache
```

## حالة الإصدار

لم يُنشر مرشح v1.0.6 بعد. ستُشغّل GitHub Actions الاختبارات وLint وبناء ARM64 والتحقق من الهوية والتوقيع على commit الإصدار؛ بعد نجاحها سيُنشر إصدار تجريبي prerelease في مستودع `hoodmoshla/Nazelha` مع APK وملف SHA-256. ملف حمولة v1.0.5 السابق محفوظ كمرجع غير نهائي ولن يُنشر على أنه الإصدار المكتمل.
